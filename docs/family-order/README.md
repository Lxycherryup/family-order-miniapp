# 家庭微信小程序点餐系统

本项目用于实现仅供自己和家人使用的微信小程序点餐系统。

## 应用组成

- `server/`：GoFrame 后端服务。
- `admin-web/`：Vue 管理后台。
- `miniapp/`：微信小程序端。
- `deploy/`：Nginx、Docker Compose 和 K8s 部署配置。

## 第一版范围

- 菜品分类管理。
- 菜品管理。
- 微信 OpenID 白名单。
- 小程序点餐。
- 订单状态处理。
- Docker Compose 部署。

## 非目标范围

第一版不支持支付、配送、打印机、多门店、库存、优惠券和商业报表。
